<objective>
Build the riskiest sixty lines in the project: six concurrent OpenRouter calls where one stalled frontier model must cost exactly one abstention and nothing else.

Two things carry this plan. First, `reasoning.effort` forced to `none`/`minimal` per model, or the `reasoning` key omitted entirely for Anthropic — without it, time-to-first-token alone runs 16 to 131 seconds on several of these models and the 30-second budget fails outright. Second, per-model failure isolation implemented INSIDE each coroutine, with `asyncio.gather(return_exceptions=True)` present only as a backstop against a programming bug, never as the mechanism.

Purpose: make partial failure the normal, boring case.
Output: `orchestrator/client.py` and `orchestrator/fanout.py`, both fully testable against `httpx.MockTransport` with no credentials.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Bot process → openrouter.ai | `OPENROUTER_API_KEY` and the user's image bytes cross here, six times per question |
| OpenRouter response → pydantic contract | Fully untrusted JSON, possibly attacker-shaped via image-embedded text, enters the type system here |
| Exception text → abstain reason → reply | A provider error string could otherwise reach the user's chat |
| Request/response bodies → log sink | Base64 image data and the API key both live in this data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information disclosure | `client.call_model` logging the request payload or response body | mitigate | Logging is restricted to model id, token counts, and `cost_usd`; an acceptance criterion greps for the absence of payload/data-url/Authorization logging. `DEBUG_LOG_RAW_BODIES` stays off by default and is not read in this plan. |
| T-05-02 | Information disclosure | A provider error body echoed to the user via `abstain_reason` | mitigate | `abstain_reason` is a short machine token (`timeout`, `http_error:500`, `transport_error:ConnectError`); the full exception is logged server-side only. |
| T-05-03 | Denial of service | One stalled frontier model consuming the whole 30s budget | mitigate | `asyncio.wait_for` at 22s inside each coroutine is the primary bound; a 26s `wait_for` around `gather` is the circuit breaker. Verified by a sub-1-second test with a 5-second straggler. |
| T-05-04 | Denial of service | Repair retries multiplying cost and latency without bound | mitigate | Exactly one repair per model per round, enforced by a test asserting no model ever issues more than 2 HTTP requests. |
| T-05-05 | Tampering | The repair call silently changing a model's vote | mitigate | `build_repair_payload` carries no image, no `SYSTEM_PROMPT`, and no grading rules; `raw_first_response` is retained on every repair so the change is auditable. Asserted by a test on the serialized repair body. |
| T-05-06 | Tampering | Instruction text embedded in a user image steering a model's JSON | mitigate | Output is constrained by `response_format: json_schema` AND independently revalidated with `Verdict.model_validate_json`; a response that does not match the contract abstains rather than being trusted. |
| T-05-07 | Spoofing | Requests being sent somewhere other than OpenRouter | mitigate | The URL is built from `settings.openrouter_base_url`, which has a fixed default and is never derived from user input. httpx verifies TLS certificates by default and that default is not overridden. |
| T-05-08 | Elevation of privilege | API key leaking into a traceback | mitigate | The key is typed `SecretStr` and unwrapped only at the header-construction line; `str(payload)` never contains it, asserted by a test. |
</threat_model>
